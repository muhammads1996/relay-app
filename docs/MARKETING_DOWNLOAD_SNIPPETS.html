How to verify your download

To confirm the MSI is authentic and untampered:

1. Download SHA256 Checksum

From the release page, download SHA256SUMS-windows.txt.

2. Verify on Windows (PowerShell)
# Compare your downloaded file
$file = "C:\Users\YourName\Downloads\Relay-windows-x64.msi"
$downloaded = (Get-FileHash $file -Algorithm SHA256).Hash.ToLower()
$expected = "abc123def456..." # from SHA256SUMS-windows.txt

if ($downloaded -eq $expected) {
  Write-Host "✓ Checksum verified! File is authentic." -ForegroundColor Green
} else {
  Write-Host "✗ Checksum mismatch! Do not install." -ForegroundColor Red
}
3. Signature Verification (Signed Releases Only)
Get-AuthenticodeSignature "Relay-windows-x64.msi"
# Look for Status: Valid and trusted signer
